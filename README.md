# Agente-de-Intelig-ncia-de-Conte-do-AWS-com-IA
Este workflow cria um assistente de pesquisa automatizado. Quando um usuário envia um tema no chat, o sistema busca artigos em um feed RSS, filtra e organiza os dados, e utiliza um agente de IA para gerar um relatório com resumo, insights e recomendações.
